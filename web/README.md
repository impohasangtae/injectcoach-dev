# Web Interface

Web-based user interface for InjectCoach.

## Planned Features

- Injection site selection
- Rotation history
- Real-time angle status
- Contact status
- Hold-time progress
- Current system state
- Session result

## Role

The web interface serves as the human-machine interface (HMI).

Sensor acquisition, state recognition, and real-time feedback are handled by the ESP32 embedded system.
