# Firmware

ESP32 firmware for the InjectCoach prototype.

## Planned Modules

- Sensor acquisition
  - MPU6050 angle sensing
  - FSR contact sensing
  - Plunger button input
- State machine
- Hold-time measurement
- Real-time feedback control
  - LED
  - Vibration motor
  - Buzzer
- Wi-Fi communication
- Web interface communication

## Current Status

Individual hardware components have been tested.
Sensor integration and the complete state machine are under development.
